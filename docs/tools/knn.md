# gric-knn: Out-of-Core Metric-Pruned k-NN Solver & Reconstruction

`gric-knn` is a high-performance $k$-nearest neighbors search solver designed to query
large-scale sequential datasets using the cluster anchors and metric distance bounds
generated by `gric-cluster`. `gric-knn-avg` provides complementary feature reconstruction
and manifold averaging using the resulting k-NN connectivity graph.

---

## 1. Overview & Architecture

Computing exact all-pairs $k$-NN on large datasets ($N \ge 10^5$) with naive methods requires
$O(N^2)$ distance evaluations and massive memory. `gric-knn` eliminates **95%–99%** of distance
evaluations by utilizing:

1. **Triangle Inequality Anchor Lower Bounding**: Uses precomputed cluster centroids (`anchors.bin`
   or `anchors.txt`) and inter-cluster bounds (`dcc.bin` / `dcc.txt`) as metric pivots.
2. **Lattice & Vector Quantization (EQ16, SQ16, RQ8, RaBitQ, PQ)**: Employs fast SIMD
   FastScan vector screening to compute distance bounds at $4\times$ to $16\times$ compression.
3. **Out-of-Core Chunk Streaming**: Maintains a strictly bounded resident RAM footprint while
   processing datasets with millions of high-dimensional vectors or images.
4. **Multi-Threaded Priority Queues**: Scales linearly across OpenMP CPU cores using bounded max
   heaps with branchless sift-down operations.
5. **Symmetric Reciprocal Distance Sharing**: Reuses computed metric distances symmetrically across
   query pairs to cut operations in half (`-no-reciprocal` to disable).
6. **2-Hop Candidate Injection & Graph Routing**: Explores nearest neighbors of top-ranking
   candidate seeds to rapidly collapse search radius $\tau$ before candidate cluster evaluation.

## 2. Usage & Options

```bash
gric-knn <input_data> <cluster_dir> [options]
```

### Core Search Options

| Option | Argument | Description | Default |
| :--- | :--- | :--- | :--- |
| `-k` | `<int>` | Number of nearest neighbors to retrieve | `50` |
| `-query` | `<path>` | External query dataset (cross-dataset k-NN mode) | In-dataset |
| `-o`, `--output` | `<path>` | Output destination file (`.txt`, `.bin`, `.fits`) | Auto |
| `-dtmin` | `<int>` | Min frame index separation $\|i - j\| \ge \text{dtmin}$ | `1` |
| `-past` | Flag | Search only among preceding frames ($j < i$) | Disabled |
| `-future` | Flag | Search only among subsequent frames ($j > i$) | Disabled |
| `-eps` | `<float>` | $(1 + \epsilon)$-ANN relaxation slack factor | `0.0` |
| `-rlim` | `<float>` | Cutoff radius (prunes neighbors beyond $r_{\text{lim}}$) | $\infty$ |
| `-double` | Flag | Run computations in 64-bit double precision | `float32` |
| `-nthreads` | `<int>` | Number of OpenMP worker threads | All cores |
| `-progress` | Flag | Display interactive live progress bar | Disabled |
| `-v`, `-vv` | Flag | Verbosity level (summary vs per-chunk telemetry) | Level 1 |

### Pruning & Metric Filters

| Option | Argument | Description | Default |
| :--- | :--- | :--- | :--- |
| `-multipivot` | Flag | Enable multi-anchor AESA pivot lower-bounding | Enabled |
| `-angular` | Flag | Enable angular cosine directional bounding | Enabled |
| `-no-angular` | Flag | Disable angular cosine directional bounding | Disabled |
| `-trajectory` | Flag | Enable trajectory momentum for smooth paths | Disabled |
| `-two-hop` | Flag | Enable 2-hop candidate injection | Enabled |
| `-two-hop-seeds` | `<int>` | Number of top seeds to expand in 2-hop | `2` |
| `-two-hop-max` | `<int>` | Max 2-hop candidates evaluated per query | `32` |
| `-approx` | Flag | Fast approximate graph search (10-20 evals/query) | Disabled |
| `-ef-search` | `<L>` | Approximate search candidate pool size | `2*k` |
| `-cluster-graph` | Flag | Graph-guided cluster routing traversal | Enabled |
| `-ef-cluster` | `<int>` | Max clusters to evaluate in graph routing | `0` (auto) |
| `-no-reciprocal` | Flag | Disable symmetric reciprocal distance push | Disabled |
| `-no-batch-dist` | Flag | Disable multi-vector SIMD batch distance evaluation | Batching on |

## 3. Quantization Modes & Sidecars

`gric-knn` features several vector quantization schemes to accelerate candidate filtering:

### E8 Gosset Lattice Quantization (`-eq16`)
- Quantizes 8D vector slices onto the dense $E_8$ Gosset root lattice.
- `-eq16`: Enable 16-bit E8 lattice quantization filtering.
- `-eq16-adc`: Enable Asymmetric Distance Computation (ADC) (default: on).
- `-eq16-sparse`: Enable SparseCache Direct SIMD (0 MB resident index RAM, default: on).
- `-eq16-ratio <alpha>`: Max quantization step ratio (default: `0.05`).
- `-eq16-save <path>` / `-eq16-load <path>`: Cache quantized representations to disk.

### Scalar Quantization (`-sq16` / `-sq8`)
- `-sq16`: Enable 16-bit scalar quantization filtering (default: on).
- `-sq16-sparse`: Direct SIMD screening from cluster-contiguous quantized memory.
- `-sq16-sparse-lru`: 16-block LRU transposed FastScan (512 KB per thread in L2 cache).
- `-sq8`: Enable 8-bit scalar quantization filtering.
- `-sq16-save` / `-sq16-load`, `-sq8-save` / `-sq8-load`: Sidecar cache persistence.

### Residual & Randomized Bit Quantization (`-rq8` / `-rabitq`)
- `-rq8`: Enable 8-bit residual vector quantization filtering.
- `-rq8-adc`: Asymmetric Distance Computation for RQ8 (default: on).
- `-rq8-e8`: Residual quantization using E8 Gosset lattice blocks.
- `-rabitq`: Randomized Bit Quantization with 1-bit or 2-bit codes (`-rabitq-bits <1|2>`).
- `-pq`: Product Quantization FastScan (`-pq-m <subspaces>`, `-pq-bits <4|8>`).

## 4. CUDA GPU Acceleration

When compiled with `-DENABLE_CUDA=ON`, `gric-knn` supports GPU acceleration via:

- **cuBLAS Batched GEMM**: Exploits Tensor Cores for Euclidean distance cross-terms:
  $\|q - c\|^2 = \|q\|^2 + \|c\|^2 - 2 \langle q, c \rangle$.
- **Micro-Batching (`-gpu-batch-size <size>`)**: Tunes between low-latency streaming
  (`-gpu-batch-size 1`) and high-throughput offline batching (`-gpu-batch-size 128`).
- **GPU Cluster Probing (`-gpu-nprobe <N>`)**: Restricts GPU distance evaluations to the most
  promising candidate clusters, pruning distant clusters directly on device.
- **On-Chip Register Priority Heaps**: Maintains sorted top-$k$ nearest neighbors in GPU
  register memory without round-trip host synchronization.

## 5. Manifold Reconstruction: `gric-knn-avg`

`gric-knn-avg` reconstructs vectors, frames, or feature targets $B$ using the neighborhood
connectivity graph and metric weights discovered by `gric-knn`:

```bash
gric-knn-avg <knn_result_dir> <dataset_B> [options]
```

### Options
* `-o <path>`: Output destination path for reconstructed file (default: `<knn_dir>/knn_recon.bin`)
* `-w <uniform|idw>`: Neighbor weighting scheme (`uniform` average or Inverse Distance Weighting)
* `-alpha <exp>`: IDW distance decay exponent: $w_j = d_j^{-\alpha}$ (default: `1.0`)
* `-v`: Verbose processing output
* `-h`: Display command-line usage summary

## 6. Examples

```bash
# 1. Standard k-NN search on 2D coordinates
gric-cluster 0.1 spiral.txt -outdir spiral_out/
gric-knn spiral.txt spiral_out/ -k 10 -dtmin 5 -o knn_results.txt

# 2. High-dimensional image k-NN with E8 lattice quantization
gric-cluster a1.5 observations.fits -outdir obs_out/ -eq16
gric-knn observations.fits obs_out/ -k 20 -eq16 -progress

# 3. Cross-dataset querying (query new test observations against training index)
gric-knn train.fits train_out/ -query test.fits -k 10 -o test_knn.bin

# 4. GPU-accelerated Tensor Core batch k-NN
gric-knn observations.fits obs_out/ -k 50 --gpu -gpu-batch-size 128

# 5. Frame reconstruction via Inverse Distance Weighting
gric-knn-avg obs_out/ noisy_frames.fits -w idw -alpha 2.0 -o denoised_recon.fits
```
