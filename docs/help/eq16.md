# eq16

## ROLE
16-Bit E8 Gosset Lattice Quantization & FastScan Filtering

## FUNCTION
Compresses frame residual vectors onto the 8-dimensional $E_8$ Gosset root lattice, enabling
vectorized FastScan filtering with bounded quantization distortion.

## ALGORITHM
The $E_8$ Gosset lattice is the densest sphere packing in 8 dimensions, offering optimal
quantization noise properties. Residual coordinates are segmented into 8D blocks and projected
onto $E_8$ lattice points:
- Distances are evaluated using Asymmetric Distance Computation (ADC), comparing unquantized query
  vectors directly against quantized lattice codes.
- Candidate blocks are screened 32 at a time using AVX2 or AVX-512 SIMD vector lanes.
- Candidates exceeding the triangular cutoff bound are discarded without computing full exact
  distances.

## OPTIONS
- `-eq16`: Enable 16-bit E8 lattice quantization filtering
- `-no-eq16`: Disable E8 lattice quantization filtering
- `-eq16-adc`: Enable Asymmetric Distance Computation (ADC, default: on)
- `-no-eq16-adc`: Disable ADC (use symmetric lattice evaluation)
- `-eq16-ratio <alpha>`: Max quantization step ratio (default: 0.05)
