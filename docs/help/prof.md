# prof

## ROLE
Dataset Profile Loading & Auto-Discovery

## FUNCTION
Loads precomputed statistical metrics, radius scale factors, and acceleration presets from a
`.gricprof` profile file generated by `gric-probe`.

## DETAILS
- When processing an input file `<dataset>`, `gric-cluster` and `gric-knn` automatically check for
  an adjacent `<dataset>.gricprof` file.
- If found, median step distances, dimension counts, and calibrated presets are loaded to configure
  optimal runtime parameters automatically.
- Specifying `-prof <path>` overrides auto-discovery with an explicit profile path.

## OPTIONS
- `-prof <path>`: Load dataset profile from specified `.gricprof` file
- `-no-prof`: Disable automatic lookup and loading of `.gricprof` profile files

## SEE ALSO
- `-preset`: Select calibrated radius preset from loaded profile
- `gric-probe`: Dataset characterization and profile generation utility
