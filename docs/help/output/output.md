# output

## OVERVIEW
All output files are written to a directory named `<input>.clusterdat/` by default
(override with `-outdir <path>`).

GRIC writes both standard human-readable ASCII tables and high-performance self-describing
binary format files (`.bin`) for instant deserialization and memory mapping.

## CORE OUTPUTS (Enabled by Default)
The following artifacts are generated by default during clustering:

- `frame_membership.txt` / `frame_membership.bin` (`-membership` / `-no_membership`):
  Frame index to assigned cluster index mapping. For streams, also includes telemetry.
- `dcc.txt` / `dcc.bin` (`-dcc` / `-no_dcc`):
  Inter-cluster pairwise Euclidean distance matrix ($D_{CC}$).
- `cluster_counts.txt` / `cluster_counts.bin` (`-counts` / `-no_counts`):
  Number of frames assigned to each cluster.
- `anchors.txt` / `anchors.bin` / `anchors.fits` (`-anchors` / `-no_anchors`):
  Exemplar anchor frame data for each spawned cluster.
- `frame_evals.txt` (`-evals` / `-no_evals`):
  Detailed per-frame candidate evaluation logs and distance traces.
- `cluster_run.log`:
  Execution summary containing throughput, timing, and metric pruning efficiency.

## OPTIONAL OUTPUTS
The following artifacts are enabled on demand:

- `transition_matrix.txt` (`-tm_out`):
  Learned Markov transition count matrix between clusters.
- `average.fits` / `average.txt` / `average.png` (`-avg`):
  Mean frame (stack) per cluster for SNR improvement.
- `*.clustered.txt` (`-clustered`):
  Input data points grouped by their cluster assignment.
- `cluster_X/` (`-clusters`):
  Individual directories containing member frames.
- `discarded_frames.txt` (`-discarded`):
  Frame indices from clusters evicted under `-maxcl_strategy discard`.
- `distall.txt` (`-distall`):
  Log of all computed pairwise distances with metadata.
- `dccmin.txt` (auto-generated when `-sparse_dcc` is enabled):
  Sparse inter-cluster lower-bound matrix.

## SEE ALSO
- `-outdir`: Specify output directory
- `-avg`: Compute average frame per cluster
- `-pngout`: Write output as PNG images
- `-fitsout`: Force FITS output format
- `-dcc`: Enable/disable dcc.txt output
- `-no_dcc`: Disable dcc.txt output
- `-tm_out`: Enable transition_matrix.txt output
- `-anchors`: Enable anchor output (default: on)
- `-no_anchors`: Disable anchor output
- `-counts`: Enable cluster_counts.txt output (default: on)
- `-no_counts`: Disable cluster_counts.txt output
- `-membership`: Enable frame_membership.txt output (default: on)
- `-no_membership`: Disable frame_membership.txt output
- `-evals`: Enable frame_evals.txt output (default: on)
- `-no_evals`: Disable frame_evals.txt output
- `-discarded`: Enable discarded_frames.txt output
- `-clustered`: Enable *.clustered.txt output
- `-clusters`: Enable individual cluster directories
- `-shm`: Enable shared-memory telemetry output
