# sq16

## ROLE
16-Bit Scalar Quantization Filtering

## FUNCTION
Compresses vector dimensions into unsigned 16-bit integers (`uint16_t`) for fast SIMD screening
and reduced memory bandwidth.

## ALGORITHM
Maps each dimension linearly from continuous floating-point values into 65,536 discrete bins:
- The quantization scale is chosen such that the maximum total distance error satisfies:
  $\sqrt{D} \cdot \text{scale} \le \alpha \cdot r_{\text{lim}}$ (where $\alpha = 0.05$ by default).
- During candidate testing, conservative lower bounds derived from quantized distances allow
  pruning false candidates without computing full floating-point Euclidean distances.
- Compatible with direct cluster-contiguous memory layouts and AVX2/AVX-512 FastScan SIMD loops.

## OPTIONS
- `-sq16`: Enable 16-bit scalar quantization filtering
- `-no-sq16`: Disable 16-bit scalar quantization filtering
- `-sq16-ratio <alpha>`: Max quantization step ratio (default: 0.05)
- `-dcc-sq16`: Store pairwise inter-cluster DCC matrix in 16-bit quantized format
