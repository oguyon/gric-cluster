# preset

## ROLE
Radius Preset Selection from Profile

## FUNCTION
Selects a pre-calibrated radius threshold $r_{\text{lim}}$ from the active dataset profile
(`.gricprof`), eliminating manual threshold guessing.

## DETAILS
Profiles generated by `gric-probe` define three standard operational points:
- `fine`: Half of the median inter-frame distance ($0.5 \times d_{\text{med}}$). Creates tightly
  bounded, high-fidelity clusters for precise representation.
- `balanced`: The median inter-frame distance ($1.0 \times d_{\text{med}}$). Recommended general
  trade-off between cluster count and speed.
- `coarse`: Double the median inter-frame distance ($2.0 \times d_{\text{med}}$). Groups broadly
  similar frames into fewer, larger clusters.

## OPTIONS
- `-preset <fine|balanced|coarse>`: Select clustering radius preset from dataset profile

## SEE ALSO
- `-prof`: Load dataset profile file
- `-auto_rlim`: Auto-scaled rlim based on runtime nearest-neighbors
