# Uniform 3D Random Distribution

**Category**: 3D Manifolds  
**Data Type**: `txt` (20,000 frames)  
**Clustering Parameter**: `rlim = 0.20`

---

## Scenario Overview

Uniform 3D volume filling. Evaluates 3D metric packing and upper/lower bound pruning across
280+ clusters.

## Execution Commands

### 1. Data Generation
```bash
gric-mktxtseq \
    20000 \
    3Drand.txt \
    3Drand
```

### 2. Clustering Execution
```bash
gric-cluster \
    0.20 \
    -maxcl \
    2500 \
    -maxim \
    20000 \
    -outdir \
    out_3Drand \
    -clustered \
    3Drand.txt
```

### 3. Diagnostic Visualization
```bash
gric-plot 3Drand.txt \
    out_3Drand/cluster_run.log \
    docs/benchmarks/images/3Drand.png
```

## Algorithmic Insights

Triangle inequality pruning scales well to 3D volume, requiring **4.85 sample calls per frame**
out of 278 active clusters.
